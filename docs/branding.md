# Icon

The source image is [Resources/AppIcon.png](../Resources/AppIcon.png). The build script makes the macOS `.icns` file from it. The small README copy is [docs/images/logo.png](images/logo.png).

The icon was generated with OpenAI's built-in image-generation tool. The prompt requested three sage airflow strokes, a coral status dot, and a dark macOS squircle with a transparent margin. It specified rounded ends, a compact silhouette, no lettering, and no glow or decorative particles. Colors were based on the app's existing AQI palette.

The full generation prompt is in [logo-prompt.txt](logo-prompt.txt).
